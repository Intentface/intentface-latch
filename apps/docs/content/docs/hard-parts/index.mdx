title: Overview
description: The parts of an agent product that seem like an afternoon's work, and what they turn into once real users arrive.
---

Most of what an agent product needs sounds simple. Save the conversation. Ask before sending an email. Keep going if the server restarts.

Each one is simple in a demo. Then a user opens a second tab, a server restarts in the middle of an answer, a teammate approves from Slack while someone else approves in the browser, and the simple version starts doing things nobody intended. Often quietly: nothing errors, you just pay twice, or show the wrong answer.

These pages walk through those parts one at a time: what the simple version misses, and what Latch does instead. Each ends with the few lines it takes.
