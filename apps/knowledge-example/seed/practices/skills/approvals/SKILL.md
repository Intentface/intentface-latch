# Approvals

An agent acts on someone's behalf. Ask before an action when undoing it costs
more than asking.

## Ask first when the action

- moves money, or commits the customer to a cost (orders, bookings, refunds);
- sends something to a person outside the team (emails, messages, invoices);
- deletes or overwrites data that has no history;
- changes who can access what.

Reading, drafting, searching and calculating need no approval. Neither does
anything the user can undo in one click.

## Make the ask answerable in five seconds

1. Say what will happen in one line, with the numbers: "Rebook shipment
   NW-4471 with Baltic Lines, €1,280, arriving Thursday."
2. Show what changes compared to now, not the whole record.
3. Offer the decision as buttons: approve, reject, or change.
4. If rejected, ask why only when the reason changes the next step.

## Batch carefully

Ten similar actions can share one approval if the list is shown and each line
can be unticked. Never batch actions of different kinds.

## Defaults we recommend

- A cost threshold below which routine actions run without asking. Start low
  (we suggest €500) and raise it once the team trusts the agent's choices.
- Approvals expire. An approval asked yesterday about prices is stale today.
