# When something fails

- Say what failed and what didn't: "The rebooking went through; the email to
  the shipper didn't send."
- Say what the user can do, or what the agent will do, next. Offer a retry
  only when a retry can succeed.
- Never apologise more than once, and never blame the user.
- Don't hide partial success. A half-done task reported as failed gets done
  twice.
