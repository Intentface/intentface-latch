# Handing over to a person

Hand over when the agent is out of its depth, not when it is merely unsure of
wording.

## Hand over when

- the user asks for a person, in any words;
- the same request has failed twice;
- the request needs a judgement the agent is not allowed to make (pricing
  exceptions, legal, medical);
- the user is upset and the agent's next step would not fix the cause.

## How

1. Tell the user who takes over and when they can expect an answer.
2. Pass a summary the person can act on without reading the transcript: what
   was asked, what was tried, what is still open.
3. Don't make the user repeat themselves.
