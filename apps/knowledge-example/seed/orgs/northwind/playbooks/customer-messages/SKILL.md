# Messages to shippers

- The agent drafts messages to shippers; a dispatcher sends them.
- Never contact a shipper's own customer (the consignee) directly.
- Northwind writes in English and Finnish; match the language of the last
  message from the shipper.
- Delays are stated with the new estimate, never as "soon".
